# QuoteCraft  

<img src="QuoteCraft/Images/QuoteCraft.png" width="75%">  

This SwiftUI app lets users discover, favorite, and organize inspiring quotes. ✨  
On every app start a random quote with its author is displayed. Users can refresh the quote, save favorites, and explore them in a dedicated list.  

This project was the **first group project** of our training, developed collaboratively as a team.  

## Features  

- ✅ Display a random quote with author on app start  
- ✅ Refresh quotes via button  
- ✅ Mark quotes as favorites with a single tap  
- ✅ View all favorites in a sheet  
- ✅ Persistent storage of favorites using **SwiftData**  
- ✅ Ability to delete quotes from favorites  
- ✅ Category system to filter and display quotes by favorite categories  
- ✅ Automatic display of quotes from favorite categories on the start page  
- ✅ Optional design enhancements: background colors or images for quotes/categories  
- ✅ Share quotes as an image (experimental feature)  

## Technologies  

- SwiftUI  
- SwiftData for persistent storage of favorites  
- @State, @Binding for state management  
- Lists, sheets, and buttons for UI interaction  
- Randomization for quote selection  
- Navigation and presentation with SwiftUI sheets  

## How to Run  

1. Click the green **"Code"** button on this repository and select **"Open with Xcode"** (if available), or download the ZIP and open the project manually.  
2. Alternatively, open the `.xcodeproj` or `.xcworkspace` file directly in **Xcode**.  
3. Click the **Run** ▶️ button in the top toolbar to build and launch the app in the iOS Simulator or on a physical device.  
4. Use the app to explore quotes, mark favorites, and organize them by categories.
